# Música

## Ruta

```text
assets/audio/musica.mp3
```

## Configuración

```js
musica: {
  activa: true,
  archivo: "./assets/audio/musica.mp3"
}
```

## Recomendaciones

- MP3.
- 128–192 kbps.
- Estéreo.
- Inicio y final suaves.
- Evitar picos bruscos.
- Si se usará en loop, procurar una edición que no produzca un salto notorio.

## Comportamiento

La invitación intenta iniciar el audio al tocar el sello. Si el navegador lo bloquea, el botón flotante permite iniciarlo manualmente.

Volumen inicial actual: aproximadamente 72%.
