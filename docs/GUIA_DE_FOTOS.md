# Guía de fotografías

## Regla principal

Las imágenes finales deben ser **fotografía limpia**.

No incluir dentro de la propia imagen:

- nombres;
- fechas;
- textos;
- botones;
- QR;
- logos;
- marcos;
- etiquetas impresas.

El HTML/CSS debe añadir todo contenido variable.

## Narrativa fotográfica

Cada fotografía debe tener un propósito distinto para evitar un catálogo de poses repetidas.

- `sobre.jpg` — mensajero y sobre con sello.
- `portada.jpg` — gran presentación.
- `historia.jpg` — momento íntimo / narrativo.
- `ceremonia.jpg` — emoción previa a la ceremonia.
- `recepcion.jpg` — foro/recepción.
- `galeria-01.jpg` — retrato editorial clásico.
- `galeria-02.jpg` — personalidad contemporánea.
- `galeria-03.jpg` — movimiento.
- `detalle-zapatos.jpg` — detalle de calzado/vestido.
- `detalle-corona.jpg` — corona/cabello/joyería.
- `detalle-ramo.jpg` — ramo/manos.
- `dresscode.jpg` — apoyo visual al código de vestimenta.
- `regalos.jpg` — detalle de regalos.
- `finale.jpg` — cierre con globos XV.

## Criterios

Variar:
- distancia focal;
- encuadre;
- pose;
- dirección de mirada;
- iluminación;
- movimiento;
- interiores/exteriores;
- planos generales, medios y detalle.

## Proporciones

Las imágenes verticales 3:4 funcionan bien para la mayoría de secciones móviles. La interfaz debe adaptarlas con `object-fit: cover` cuando sea necesario.
